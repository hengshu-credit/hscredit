# hscredit Skills 目录

当前已实现并可安装：

| Skill | 能力 | 调用 |
|---|---|---|
| `hsbin` | 分箱统计、效率评估、方法对比、可复用一维/二维分箱器和分箱图 | `$hsbin` |
| `hsreport` | 特征分析、模型评估和策略迭代完整 Excel 报告 | `$hsreport` |
| `hscredit` | 查询当前可用 Skill 和操作目录 | `$hscredit` |
| `hsmodel` | 模型、调参、Loss、评分卡、校准和解释 | `$hsmodel` |
| `hsrule` | Rule、RuleFlow、规则报告和 Swap 分析 | `$hsrule` |
| `hsselect` | 特征筛选与中文筛选报告 | `$hsselect` |
| `hsviz` | 模型、评分、策略、稳定性和树图可视化 | `$hsviz` |
| `hsexcel` | DataFrame/多表工作簿 Excel 交付 | `$hsexcel` |

安装整套时会安装以上八个 Skill。每个 Skill 都映射到 hscredit 当前公开 API 的白名单操作。
