# Notebook 演示字段集

Notebook 统一直接复用 `hscredit_dataset`，默认使用 `split=False`，通过 `columns` 在读取 Parquet 时投影字段。这里固定字段清单，不另存一份演示数据，也不要求运行 Notebook 时读取特征摘要或重新随机抽取。

## 固定字段清单与加载

下面的代码可直接作为 Notebook 的数据准备单元格。每本 Notebook 可以从统一字段集中进一步选择本节需要的列；综合特征分析与筛选示例使用完整的 88 列。

```python
from hscredit import hscredit_dataset
from hscredit.utils.datasets import HSCREDIT_EXAMPLE_COLUMNS

data = hscredit_dataset(columns=HSCREDIT_EXAMPLE_COLUMNS)
```

固定字段仅维护于 `hscredit/utils/datasets.py` 的 `HSCREDIT_EXAMPLE_COLUMNS` 常量。
编号、日期、审批额度与期数、渠道、MOB1/MOB3/MOB6 共 8 列为上下文，剩余 80 列为候选特征；每本 Notebook 显式选择实际入模列。

默认得到 111,929 行、88 列，包含 80 个候选特征和 8 个上下文字段。抽取的是字段，不是行；Notebook 保留全量订单，通过必要的字段选择、训练轮数与搜索次数控制计算量，不做行采样。

候选特征并不要求全部进入模型。随机选中的 32 列中有 8 列的非缺失唯一值数为 1，保留它们可以演示缺失率、单一值率与方差筛选；不通过重新抽取来预先排除这些情况。类别编码、填补、分箱和筛选均在训练集或交叉验证的训练折内拟合。

目标列由 Notebook 显式构造。单标签主线可使用 `MOB6 > 30`，多标签演示可使用 `MOB1`、`MOB3`、`MOB6`；实际缺失或无效逾期值不能直接记作好样本。表现期定义见[现金贷数据集说明](datasets.md)。需要核实观察时长时，按需额外投影 `放款时间`、`etl_date`；这两列不计入上述固定 88 列。

## 来源与复现

- README 字段来源：[README 数据加载与金融计算示例](showcase.md)，清单核对日期为 2026-11-09。
- 排名来源：[授信特征摘要](dataset-summary.md)及其[原始工作簿](assets/datasets/hscredit-summary.xlsx)，工作表为 `特征摘要`。第 5 行为字段标题，第 6 行起为特征；A 列是字段名，I 列是 MOB3@30 KS，M 列是 MOB6@30 KS。
- 工作簿 SHA-256：`b2b347248ca5b9d60a0a405a953b00ed56c96905f268a14f1ae99a663a7bea6f`。
- 摘要包含 8,493 个授信特征。KS 使用摘要中的现有数值，其原始说明为特征缺失填充 `-99999` 后计算；本清单不另行重算或改变 KS 口径。无有效 KS 的字段不参与 TOP32 排名。
- 随机候选池直接取摘要的全部特征名，排除三个必选集合后得到 8,445 列。按字段名排序，再用 Python 标准库 `random.Random(42).sample(pool, 32)` 抽取；不按缺失率、唯一值数或指标表现追加过滤。

TOP32 基于全量摘要预选，因此这些样例用于展示功能，模型效果不应作为完全独立于特征选择过程的泛化评估。严谨评估应在训练数据内部完成特征选择。

字段清单固定后，Notebook 运行不随摘要更新自动变化。更新清单时同时更新来源、排名口径与抽取结果，确保各模块的样本和字段仍可对照。
