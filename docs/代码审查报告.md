## 三、当前仍待处理的问题

### C-1（P2，功能）`FeatureImportanceSelector` 不支持仅有 `coef_` 的 sklearn 线性模型
- **证据**：[rfe_selector.py:110](../hscredit/core/selectors/rfe_selector.py#L110) 硬编码 `importance_getter='feature_importances_'`，但文档（[rfe_selector.py:5/36](../hscredit/core/selectors/rfe_selector.py#L36)）声称"适用于任何有 `feature_importances_` 或 `coef_` 属性的模型"。
- **实测**：`FeatureImportanceSelector(sklearn.LogisticRegression())` → `AttributeError: 'LogisticRegression' object has no attribute 'feature_importances_'`（唯一仍失败的测试 `test_selector_model_compat::test_with_sklearn_lr`）。hscredit 自带的 `LogisticRegression`（暴露 `feature_importances_`）可用。
- **建议**：改用 `importance_getter='auto'`（sklearn 自动对线性模型取 `coef_`），兑现文档承诺并修复该测试。

### C-2（P2，文档/代码不一致）`SingleFeatureRuleMiner` 的 `optimal_iv`/`cp_sat` 方法名无效
- **证据**：[single_feature.py:83 `METHOD_MAPPING`](../hscredit/report/mining/single_feature.py#L83) 不含 `optimal_iv`、`cp_sat`，但类 docstring（[行 36/77](../hscredit/report/mining/single_feature.py#L36)）与 `CLAUDE.md:151` 都示范 `method='optimal_iv'`。
- **实测**：`SingleFeatureRuleMiner(method='optimal_iv')` → `ValueError: 不支持的method: optimal_iv`。
- **建议**：将 `optimal_iv` 映射到 `best_iv`（或在 `METHOD_MAPPING` 增加别名），并同步 docstring/CLAUDE.md；`cp_sat` 同理补齐或从文档移除。

### C-3（P2，健壮性）裸 `except:` 34 处
- 集中在 [core/eda](../hscredit/core/eda)（22）、[core/viz](../hscredit/core/viz)（5）、`core/selectors`（2）。裸 `except:` 会吞 `KeyboardInterrupt`/`SystemExit` 并掩盖真实错误。
- **建议**：至少改 `except Exception` 并记 warning 日志。

### C-4（P2，代码卫生）库内 `print(` 517 处
- 分布最广：`core/selectors`、`core/binning`、`core/models`、`core/eda`。多数在 `verbose` 分支，但库代码宜走 logging（项目已有 `utils.logger`），便于分级与生产关闭。
- **建议**：`verbose` 输出改 `logger.info`；将 `flake8`（已在 dev 依赖）纳入 pre-commit/CI。

### C-5（P2，残留 TODO）基类 `plot()` 未实现
- [base.py:1858](../hscredit/core/binning/base.py#L1858) `# TODO: 实现可视化功能`。各具体分箱图已由 `core/viz/binning_plots` 提供，基类 `plot()` 仍是占位。
- **建议**：让基类 `plot()` 委托到 `core/viz` 的分箱可视化，或移除该占位方法。

### C-6（P2，少量未用局部变量）
- flake8 报告若干未用局部：`best_ks`（`good_in_bin/bad_in_bin`）、`kmeans`（`best_labels`）、`mdlp`（`n_left/n_right`）、`or_binning`/`monotonic` 多处。不影响功能，建议随 lint 清理。
