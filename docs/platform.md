# hscredit 风控平台

在 Python 环境中启动本地网页，将数据准备、探索、策略挖掘、模型比较和三方变量测试放到同一工作台。前端资源随 Python 包分发，日常使用不需要 Node.js，也不需要连接 CDN。

## 快速启动

```bash
pip install "hscredit[web]"
python -m hscredit web --demo
```

在仓库开发环境中使用 `pip install -e ".[web]"`。启动后自动打开浏览器，默认链接为 `http://127.0.0.1:8765/`。`--demo` 加载 `hscredit_dataset(columns=HSCREDIT_EXAMPLE_COLUMNS)`；首次缺少本地缓存时，由原数据加载器下载并校验数据。也可以不带 `--demo`，在页面点击“加载 hscredit 示例”。

```python
from hscredit.web import launch

# Notebook 中后台启动，不阻塞后续单元格。
server = launch(background=True, demo=True)
print(server.url)

# 可注册已有 DataFrame。
# server.add_dataset(data, name="我的数据集")

# 使用完毕后停止服务；未完成任务会停止，配置保留，可重新执行。
# server.stop()
```

普通 Python 脚本可直接调用 `launch(demo=True)`，保持前台运行。指定 `port=0` 会选取空闲端口；`data_dir` 指定持久化目录，`open_browser=False` 禁止自动打开页面。命令行对应 `--port`、`--data-dir`、`--no-browser`。也支持 `python -m hscredit.web --demo`。

## 演示数据与字段联动

使用[统一样例字段](examples-dataset.md)，不重新抽列、不抽样订单。当前数据为 111,929 行，原始投影共 88 列，其中 80 列为候选特征，8 列为上下文。平台额外构造 `MOB6大于30天` 标签：有效的 `MOB6 > 30` 为坏样本，其余有效非负值为好样本；缺失、非数值、负值和无穷值保留为缺失标签。重复点击加载会复用原示例数据集。

默认排除用户编码、授信时间、金额、期数、渠道及 MOB1/MOB3/MOB6 等上下文字段。页面预选日期 `授信时间`、金额 `loan_amt`。字段清单仍以 `hscredit.utils.datasets.HSCREDIT_EXAMPLE_COLUMNS` 为唯一来源。

示例 TOP32 特征来自全量特征摘要预选，模型结果仅作功能演示。独立泛化评估应在训练集内部进行特征选择，并按业务定义筛选表现期成熟样本。

## 配置目标变量

变量探索、策略挖掘、模型构建和三方测试共用 **配置目标变量** 弹窗。主页面显示已应用的口径；在弹窗中预览样本分布，再点 **应用配置** 生效。取消会保留原配置。

1. **选来源。** 使用「现有标签」时，选择一个或多个恰有两个非空类别的字段，逐列指定哪个值代表坏样本。例如「审批表现 = 违约」会把“违约”映射为 1，另一类别映射为 0。变量探索的字段统计也可选「无标签」查看基础统计。
2. **定义逾期口径。** 使用「逾期天数」时，选择数值字段、比较符和阈值。选择 MOB1、MOB3 并填写 `7, 30` 会生成四个口径。阈值以天为单位，允许非负小数，重复值按首次出现顺序合并。
3. **确定样本范围。** 默认按标签剔除缺失，可改为计入好样本、计入坏样本或报错。打开「剔除灰样本」后，`>` 剔除 `0 < 天数 ≤ 阈值`，`>=` 剔除 `0 < 天数 < 阈值`。`<` 和 `<=` 没有灰区。原始逾期字段中的负数按数值参与比较；如果业务上代表未成熟样本，可先在字段加工中转为缺失。
4. **核对并运行。** 点击「预览样本分布」查看当前数据版本下各口径的有效数、好坏样本数、剔除数和坏样本率。策略挖掘和模型训练默认使用第一个口径，多口径时可通过「训练主标签」切换，其余口径用于评估。训练、测试和评估集沿用同一套定义。

特征选项自动排除当前口径的来源字段。其他标识、贷后信息和可推导目标的字段仍需按业务场景筛选。

**标签字典。** 选择「标签字典」，每行填写报告中使用的标签名称、来源字段和坏样本条件。例如第一项「首逾」使用 FPD 原值，第二项「七天逾期」使用 MOB1 大于 7。页面显示「主标签 · 首逾」。点击「移至首项」可以调整默认顺序，训练任务也可以单独指定主标签。逾期天数模式默认取第一个字段与第一个阈值生成的组合。

平台 HTTP 接口用 JSON 对象传入字典。例如 `{"target":{"首逾":{"field":"FPD"},"七天逾期":{"field":"MOB1","operator":">","value":7}}}`。后台会在每份数据集上计算条件，保留来源字段的缺失，再交给 hscredit 绑定为命名标签。字典值也可以是与数据集等长、按行排列的 JSON 数组。内部划分留出集时标签随原始行切分；绑定外部数据集时，数组也需与该数据集逐行对应。原值和数组按 hscredit 的 0/1 与灰样本规则处理。

## 平台功能模块

### 从数据库导入数据集

在 **数据管理 → 数据资产 → 导入数据集** 中选择 **数据库查询**。选择数据库类型，填写连接地址和只读账号，输入取数 SQL 和数据集名称，再点 **导入并预览**。查询支持单条 `SELECT`、`WITH`、筛选和多表关联。关联结果中同名的字段需要分别指定别名。

数据库位于内网时，开启 **使用 SSH 隧道**。数据库地址按跳板机可访问的地址填写；下方的 SSH 主机、端口和用户名填写跳板机的登录信息。Oracle 经隧道连接时使用 `主机:端口/服务名`。SSH 认证方式支持：

- **账号密码**：填写 SSH 登录密码。
- **公钥**：选择与跳板机授权公钥配对的本地私钥；私钥已加密时填写私钥口令。
- **账号密码 + 公钥**：同时提供登录密码和私钥，支持跳板机要求公钥通过后再验证密码的认证流程。

平台默认按运行平台账号的 `~/.ssh/known_hosts` 核对跳板机身份，也可填写管理员提供的 SHA256 主机指纹。点击 **测试连接** 会通过当前配置执行探测查询，无需填写取数 SQL 或数据集名称。测试与导入分别建立连接，完成后关闭。凭据和私钥仅在本次请求中使用。

平台通过 `hscredit.database.Database.stream_query` 分块读取完整结果，沿用每个数据集 200 万行、2000 个字段的上限。导入后自动选中新数据集，可直接预览、划分、探索或建模。后续任务读取本次导入的本地快照。需要取最新数据时，可再次执行查询，保存为新的数据集。平台仅在导入期间使用连接参数。

支持 MySQL / MariaDB、StarRocks、Hive、Impala、Oracle、ClickHouse 和 MaxCompute。在运行平台的 Python 环境安装对应扩展，例如 `pip install "hscredit[web,db-mysql]"`。各数据库驱动见[数据库指南](database.md)。

### 数据管理中的数据集划分

在数据资产表或数据预览旁点击 **划分**。左侧以可折叠层级树显示样本去向，分支编号对应父子层级；右侧只编辑当前选中的样本，显示来源路径、当前层级及返回上级入口。开始时自行选择方法，不预设训练／验证／测试集，也不要求先按条件、再按时间。

1. 从「全部样本」选择 **按条件、按比例随机、按时间、按分组、留出时间外样本** 中任一方法。
2. 配置当前方法，给每份结果命名。名称只填写一次，同时用于概览、划分路径和最终数据集。
3. 点击任意结果的 **继续拆分**，或在左侧选中该结果，再选择任意方法。不同分支可采用不同方法和顺序；不继续拆分的结果直接保存。
4. 点击 **预览划分结果**，检查实际行数、占源数据比例、划分路径、排除数量及前 5 行，再点击 **保存划分**。修改执行配置后需要重新预览。

例如，可以先按时间拆为早期／近期样本，再将早期样本随机拆为训练／验证集。划分后既可选取完整的早期样本进行分析，也可分别选取训练集和验证集。比例始终相对于**当前选中的样本**，分组方式则相对于当前样本的组数。

| 方式 | 可配置参数与归属规则 |
| --- | --- |
| 按条件 | 支持字段比较及「全部满足／任一满足」条件组。规则从上到下首次命中，每行只进入一个结果；未命中的进入「其余样本」。可调整规则顺序，各结果均可继续拆分。 |
| 按比例随机 | 每份比例及可选分层字段；随机种子在高级设置中。固定种子复现结果，分层尽量保持各类别比例。 |
| 按时间 | 时间字段、时间边界或样本比例。结果从早到晚排列，边界时刻归入后一份。高级设置可排除边界前的间隔行。 |
| 按分组 | 分组字段、每份分组比例。同一客户或业务组不会跨本次划分的直接结果；实际行数占比可能不同。随机种子在高级设置中。 |
| 留出时间外样本 | 时间字段、起始时间、可选结束时间。第一份为起始时间之前的开发样本，第二份为时间外样本；起止边界均包含在时间外范围内。 |

随机、时间、分组支持每次拆成 2–10 份，初始两份各占 50%；时间划分默认填写日期边界。添加结果会重新均分比例，也可以手动调整或点击 **均分比例**，合计须为 100%。移除结果不改变原比例或时间边界。时间外划分固定两份。结果名称须在全树唯一，且不能与已有数据集重名。

在左侧层级树或右侧结果列表中选择 **移除结果**，该结果及其下方全部结果不再生成数据集。两份划分、时间外划分、条件命中及其余样本都支持移除。移除后保留「已移除」的位置用于核对来源，其样本计入预览中的排除数量，其他分支的比例、时间边界和样本归属保持不变；**恢复结果** 会恢复原名称、参数和完整子层级。全部结果移除后不能预览或保存，至少恢复一份结果后才可继续。

选择 **取消下方拆分，整份保存** 可将一份样本的下级划分收回为单份结果。**删除条件** 则删除整条规则，原本命中的样本会继续匹配后续规则或进入其余样本，操作前会说明影响。左侧 **撤销** 可恢复最近的结构调整（包括调整前的配置），不是逐字输入的撤销。关闭划分窗口后，未保存的配置与恢复记录会清除。

划分界面与平台共用主题变量和直角控件规范，支持浅色、深色、跟随系统、自定义纯色／渐变以及色弱辅助。选中方法以勾选和边框共同标记，层级以编号、展开箭头和文字状态呈现。

条件支持等于、不等于、大小比较、集合包含／排除、闭区间、文本包含以及为空／不为空。集合可选择示例值或输入新值后回车。普通比较不会命中缺失值，如需单独处理请使用「为空」。文本包含按字面匹配，不执行正则或代码。

比例采用最大余数法分配整数份额；时间比例以扣除间隔后的样本数为基数。按比例划分可能让相同时间的行进入相邻结果，需要整段时间隔离时请选择明确边界。时间、分组和分层字段不能包含缺失值。间隔行及时间外结束时间之后的行会排除，预览显示数量与原因。条件未命中的空分支不创建空数据集；划分方法产生空结果时需要调整参数。

预览可展开 **逐步划分明细**。每行最终只能进入一个保存结果或被排除，没有非空结果时不能保存。最多支持 100 个节点、8 层嵌套、30 个最终数据集，每个条件节点最多 20 条规则；条件组也计入节点及嵌套限制。

保存后，数据资产表按配置中的层级展示中间分组和最终子集。单击数据集或中间分组，下方会显示所选样本的数据预览。双击有下级的行，或单击名称前的小箭头，可展开或折叠该分支。中间分组的样本量、字段数和缺失比例按进入该分组时的全部行计算，包含后续步骤排除的行。非空分组均可在探索、建模、评估和报告中选用。子集和分组以行索引绑定源数据版本，首页的数据总量只统计源数据。

在中间分组行点击 **划分**，编辑该分组下的规则或比例，再预览整体结果并点击 **更新整体方案**。更新沿用方案原先绑定的源版本，同级分支保持原来的样本归属。已提交的分析任务继续使用各自绑定的数据版本。

在源数据集行点击 **划分**，会直接载入上次保存的条件、比例、种子和时间边界。如果源数据有多套方案，可在窗口顶部切换。子集行的 **重划** 会打开该子集所属的方案。修改后先预览，再点击 **更新划分**。同名结果或仅更名的原位置会沿用子集标识并生成新版本。更新使用源数据集当前版本，已绑定旧版本的任务继续按原索引读取。子集行的 **删除** 会在确认后移除所属方案及其子集。存在下级划分时，先调整或移除下级方案。

需要在同一批样本上尝试另一种划分方式时，在原始数据集行点击 **复制**。平台将原始数据集的当前版本复制为独立数据集，打开空白划分配置。新结果显示在副本下方，原方案和子集继续可用。取消划分后，副本仍保存在数据资产表中。

对于旧版保存为 Parquet 且仍保留完整来源配置的初始划分副本，平台会在原数据集下显示并允许重新划分。首次更新时发布索引版本，保留原文件供历史版本读取。已单独加工过的旧副本继续作为普通数据集使用。

### 数据管理中的字段加工

导入后，在数据资产表或数据预览旁点击 **ƒx 字段加工**。配置流程如下：

1. 选择“新增字段”或“更新原字段”，填写目标字段名。
2. 在 fx 组合表达式中选择字段、常量、函数或嵌套组合。字段内容选择器支持按类型筛选、搜索、查看示例值和双击插入；也可以插入之前步骤生成的字段。

   字段加工、样本划分、变量探索、标签、策略、模型和三方评估共用内容选择器。左侧可切换全部字段、已选字段、最近使用和字段类型。右侧支持搜索和跨页勾选，点击「确定」后生效。每页可选 10、20、50 或 100 个字段，向下滚动会接续下一页，也可点击页码跳转。悬停或点选字段可在浮层中查看当前版本的全量摘要和分布。拖动摘要标题栏可移动浮层并自动固定，也可直接勾选「固定面板」保留当前字段。前序步骤生成或更新的字段在保存加工后可查看摘要。

   多选时，「字段名称」前的勾选框可跨页选中或取消当前分类下的全部搜索结果，部分选中时显示横线。拖动经过多行或按住 Shift 点击终点可连续选择。已选字段在输入框内换行，超过可见高度时滚动查看。

   点击 **手工输入** 后输入部分名称，例如 `BASE`，下方即列出当前可选字段中的匹配项。前缀匹配排在其他包含匹配之前，单选时点一个完整字段名，多选时可连续勾选。也可直接粘贴以换行、逗号、分号、制表符分隔的清单或 JSON 字符串数组，完整字段名自动匹配；点击输入框中的某一项可查看该项的候选。核对后点 **使用匹配字段** 或 **加入已选**，再点 **确定** 应用。

3. 追加运算项并选择运算符。乘除优先；嵌套组合明确控制括号。常用加工提供单位换算、数值缺失填补、上下限截断和条件标签模板。
4. 点击“计算预览”。后台对**全部行**执行表达式，再显示前 20 行的处理前后对比，以及类型、缺失数、无穷值数和唯一值数；整列均值、合计等聚合不会误用预览样本计算。
5. 选择更新当前数据集或另存副本后保存。修改任何规则都会使原预览失效，需要重新计算。保存后字段下拉框与数据概况自动更新。

左侧使用“添加字段”配置多项加工。切换新增/更新时保留表达式和各自字段名，同一页面关闭后重新打开仍保留草稿。删除运算项会连同其嵌套子项一起删除，最后一项也可以移除；“清空表达式”删除整个配置树，空表达式不能计算或保存。

双击“组合预览”或点击“编辑表达式”，可以直接修改表达式文本，再点击“解析并回显”转换为配置控件。支持普通字段名、`col("含空格的字段名")`、括号、算术、比较、`and/or/not` 及面板内函数。解析失败保留原配置，不执行任意 Python；解析成功后需要重新计算预览。单行控件统一高度，数值常量使用普通文本输入，不带加减步进按钮。

例如，配置金额字段除以 10000、或按逾期阈值生成标签，后台生成的表达式分别为：

```python
col("loan_amt") / 10000
where(col("MOB6") > 30, 1, 0)
where(isnan(col("评分")), 0, col("评分"))
```

表达式树由服务端校验并编译，实际运算统一委托 `NumExprDerive(..., trusted_python=False)`。DataFrame 输入使用该类既有的受限 AST 和 numpy/pandas 向量运算。更新原字段时先生成临时衍生列，再映射回目标列，不改变 `NumExprDerive` 禁止覆盖原列的公开约定；步骤依次执行，后续步骤读取此前更新后的值。

支持数值运算、文本拼接与比较、布尔组合、条件取值，以及界面中列出的 NumExprDerive 函数。文本分支与数值分支不能混合，避免隐式转换把缺失值变成字符串；日期字段可复制，未支持的日期加工不会通过任意 Python 代码执行。每次最多 30 个步骤，每条表达式最多 64 个节点、8 层嵌套。

更新采用不可变的数据版本文件和原子元数据切换：任何计算或写入失败都保留旧数据。加工记录保存配置及生成表达式，可在“加工记录与版本”恢复历史内容，恢复会建立新版本。模型与报告任务绑定提交时的数据版本，重新执行沿用该版本。数据集正在被任务使用时不能原地更新，可以选择另存副本；多个页面同时修改时，旧版本请求会提示重新预览。

### 数据管理中的字段概况

在**数据预览**、**字段概况**或**任务管理**的表格上方，点击 **添加筛选字段**，选择要筛选的列。点击该行的 **添加筛选值** 选择一个或多个值，也可输入自定义文本后选择添加。添加首个值后该行条件立即生效。再次点击 **添加筛选字段** 即可叠加下一行条件。同一字段匹配任一已选值，不同字段需同时满足。可单独移除值或整行条件，点击 **重置** 可恢复全表。

数据预览从当前版本的全部样本中匹配，再分页展示。可输入关键词查找字段值，也可与整行内容搜索组合使用。字段概况可按特征名、字段类型、缺失数等统计列筛选展示的字段。任务管理可在当前模块内按状态、数据集、任务名称、数据版本和提交日期筛选，任务状态刷新后，列表会同步更新。

数据明细下方的 **字段概况** 自动显示所选数据集当前版本的无标签 `DataFrame.summary()`。原始数据集、中间分组和最终子集都使用各自的全部样本。数据明细的分页、搜索以及其他分析页面的标签设置不会改变概况。即使数据集有默认标签，该列也作为普通字段展示。概况支持按字段名或统计值搜索和分页，同一数据集版本可复用已计算的结果。

**字段相关性** 位于字段概况下方。点击「分析字段」可搜索、按类型筛选或批量粘贴字段名。默认用同一组字段两两比较；勾选「单独选择列字段」可将行、列设为不同字段组，例如只看各特征与标签的相关性。清空某组选择会恢复该组的全部字段。热力图和相关性表可直接切换，宽表支持行、列独立翻页。每个系数使用两列共同有效的全部样本。常量或有效样本不足时，图中留空，表中显示「—」。

数值对使用 Pearson r（−1 至 1），日期按 UTC 时间、布尔值按 0/1 计算。两个类别字段使用 Cramér’s V，类别与数值字段使用相关比 η，两者均为 0 至 1，表示关联强度。文本按原值视作类别，像订单编号这样每行取值都不同的类别字段可能得到很高的关联强度。

在 **数据管理 → 数据预览** 中，将鼠标停留在任意列表头，可查看该列完整数据的无标签 `summary()` 摘要及分布；也可用键盘聚焦或点击表头打开。数值显示等宽直方图，文本显示前 12 类频数条形图（其余合并），时间按跨度自动选择小时、日、月或年并绘制频数折线图，布尔显示真、假、缺失的占比环图。缺失与无效值的计数和统计口径显示在浮层内。

悬浮详情按需读取单列，不受预览分页或搜索过滤影响；同一数据版本内重复悬停复用已加载结果，切换数据集或加工后更新版本会重新计算。

勾选浮层右上角的 **固定面板** 后，鼠标移出仍保持显示；取消固定后，鼠标移出自动隐藏。点击 **关闭** 会关闭面板并取消固定。完整 summary 随外层面板一起滚动，摘要区域没有独立滚动条；固定选项和关闭按钮在滚动时仍保持可见。

拖拽标题栏可移动面板（支持鼠标和触摸），移动后自动固定；面板限制在当前窗口内，缩小窗口时也会调整位置。标题栏采用紧凑间距，固定选项和关闭按钮不触发拖拽。关闭后再次悬停，面板恢复到对应列表头旁。

### 组合变量探索

在 **数据探索** 的同一块字段布局中配置 1–3 个字段。展开 **分析样本** 可切换数据集、配置 PSI 对照或批量运行。点击 X、Y、Z 或分组标签，通过内容选择器选择字段。已选坐标轴可以拖动换位，点叉可移除。分组标签最多支持 30 类（含缺失值）。

在每个字段下拉框独立选择图形。数值支持直方图、箱线图和累计占比曲线，日期支持趋势线、分期柱状图和累计占比，类别和布尔值支持频数条形图或占比图，高基数或长文本按字符长度统计。每个字段还有分布表和按当前标签口径计算的字段统计。

添加第二、第三个字段后，每对组合都会出现独立的 **交叉图形** 选择。例如金额选箱线图、渠道选类别占比图、授信日期选趋势线；在同一结果区可同时查看分渠道金额均值、分期金额均值和渠道与日期的透视交叉表。两个数值字段可查看散点、密度和全量配对的 Pearson 相关系数，两个类别字段可看堆叠频数。点击 **运行分析** 生成所有子图及统计表；在结果区切换图形或展开明细直接复用本次数据。

三变量结果依次展示联合分析、所有两两交叉及单字段分布。在联合分析中可切换三维图和多级透视表。二变量使用 2×2 看板，左上为交叉图或表，右上和左下为两个字段的分布，右下为交叉摘要。在 **布局与显示** 中调整主列宽度、两行高度，或多图的每行列数和子图高度。

**透视交叉表** 只使用当前组合的分析字段。选择某个行列位置上的字段，可与另一位置交换；三字段布局还可将一层移到另一侧，或点击 **互换行列** 转置整张表。要更换分析字段，请回到上方 **字段布局** 并重新运行。透视表默认计算样本数，也可使用本组合中的值字段计算有效计数、去重计数，或对数值求和、均值、中位数、最小值和最大值。合计按完整的筛选结果计算。**透视表设置** 可切换原始值与分析轴分箱、多级或平铺表头、小数位、行距及合计。

配置目标变量后，**目标标签概况** 会逐项列出有效、好、坏及剔除样本数。坏样本率以各标签自己的有效样本为分母。通过 **图表目标标签** 选择口径，再选择有效、好或坏样本，可联动查看字段分布、二维交叉、三维图和透视表。二维图的分组筛选可叠加使用。选择 **全部样本** 可恢复原结果。

**全表数据检查** 用于判断是否需要处理缺失值或核查重复导入：缺失单元格比例是全表缺失单元格数除以总单元格数；完全重复行数是所有字段都相同的额外行数，首次出现不计入。该检查始终针对完整数据集。图表旁的 **字段统计** 展示当前字段的 `summary` 内容。在 **配置目标变量** 中选择标签，点击 **运行分析** 后可查看对应的 IV、KS、AUC 和趋势，多标签时保留指标分组。切换分析字段并运行后会复用同一配置的缓存摘要。用作监督标签的字段仍可查看分布。数值直方图自身仍排除缺失和无穷值。

选择时间字段后，可配置 **时间汇总频率**，默认 `M` 按月统计样本数。支持日 `D`、周 `W`、季度 `Q`、年 `Y`、小时 `h`，以及手动输入 `2W`、`MS`、`15D` 等 pandas `resample` 频率。后台使用完整数据的有效日期执行 `resample(freq).size()`，时间空档补零，缺失与无效日期单独计数；带时区时间统一为 UTC。边界遵循 pandas 默认规则，例如 `W` 以周日为边界、`M` 以月末为边界。超过 10,000 个时间段时提示改用更粗频率，不静默截断。

修改图表字段或频率后点击 **运行分析** 生效，页面会标记未应用的配置并保留上次结果的实际字段标题。频率变化只重算图表，复用未变化的字段概况。分布图的 x 轴标签与底部区间滑块分区显示，长标签省略时可通过图中悬浮提示查看完整值。

变量探索按分析样本版本、对照样本版本和标签配置缓存统计结果。标签缺失仅影响对应标签的预测指标。未选 PSI 对照样本时，使用 `summary` 默认的固定种子随机拆分口径。

### 按用途选择数据集

在「数据集配置」选择主样本。原表和划分子集按层级展示。需要评估同一套规则或同一个模型时，在「其他评估样本」中选择验证集、时间外样本（OOT）或其他客群。模型的「主测试方式」决定预测明细和主测试指标使用哪些行。

| 页面 | 页面中的选择 | hscredit 实际收到的数据 |
| --- | --- | --- |
| 数据探索 | 一份分析样本或多份批量样本，可选 PSI 对照样本 | 每份分析样本分别计算字段分布和交叉结果。PSI 使用同名字段对照，字段统计沿用已配置的标签口径。 |
| 单变量、双变量策略 | 一份拟合样本，可加多份评估样本 | 先在拟合样本上训练分箱器，再分别向 `feature_bin_stats` 或 `feature_bin_stats_2d` 传入各表与同一个已拟合的分箱器。 |
| 二叉树、多叉树策略 | 一份拟合样本，可加多份评估样本 | 树在拟合样本上训练。树报告接收 `{样本名称: DataFrame}`，在各份样本上评估相同节点。 |
| 规则集评估 | 一份主评估样本，可加多份其他评估样本 | 将同一组既定规则逐表传给 `Rule.report`、`ruleset_analysis` 和 `swap_out_report`，每份样本生成一份置换报告。 |
| 模型实验、模型对比 | 一份训练样本；选择分层留出、独立测试或训练集内评估；可另加多份评估样本 | `ModelTuner` 只在训练部分交叉验证。`compare_models` 使用共同的训练和主测试样本。`auto_model_report(datasets={样本名称: (X, y)})` 对同一模型、同一标签横向统计各样本，结果可在「跨样本指标」中查看。 |
| 三方测试 | 一份报告样本，或批量生成报告 | `auto_feature_analysis(data=明细表)` 每次生成一份独立分箱的报告。 |

例如，要用开发集建模、在测试集核对预测、在时间外样本看稳定性，选择「训练样本 = 开发集」「主测试方式 = 独立测试集」「独立测试样本 = 测试集」「其他评估样本 = OOT」。提交一次模型实验即可。默认的分层留出比例为 25%，选择独立测试后，整份训练样本用于拟合。

需要对多份样本**各自重新拟合或出报告**时，打开 **配置样本**，添加「追加独立运行样本」。每份主样本生成一项任务，沿用该页选择的测试和评估配置。数据集版本在提交时锁定，批次内全部样本通过校验后统一入队。可在「查看本次运行结果」切换任务。数据管理中的划分负责生成这些样本；PaaS 发布使用已生成的制品，样本预测解释单独选择待解释的数据集和行号。

### 任务管理

模块页面展示本次提交的结果。点页面顶部的 **查看历史任务**，可进入该模块的任务列表。也可以从主导航进入 **任务管理**，切换数据探索、策略挖掘、模型构建、三方测试四个页签。每个页签汇总所有数据集和版本的提交记录。多变量交互归入数据探索，规则集评估归入策略挖掘，样本预测解释归入模型构建。

点击 **查看详情** 可跟踪进度或查看失败原因。任务成功后，点 **查看报告** 即可在网页阅读 Excel，也可在模块的本次结果中打开。通过工作表目录或表内的目录链接切换章节；合并表头、百分比、数值精度及工作表图片按报告内容展示。横向滚动直接读取可见列，纵向滚动自动接续可见行。行分页每 50 行一页，可直接跳页；翻页等待读取期间仍可查看原内容。点图片可放大，点 **全屏阅读** 可展开阅读区域。点击 **下载 Excel 报告** 获取原工作簿。模型、预测明细等在 **其他产物** 中下载。历史成功任务若只保存了分析结果，平台会在首次预览或下载时用已保存的结果生成 Excel。

点击 **重新配置**，可沿用原数据版本，也可更换数据集、版本和分析参数。**编辑完整配置** 提供标签口径、模型参数、评估样本等完整设置。点 **提交新任务** 会创建独立记录，并打开新任务详情。原任务会按提交时的配置继续执行，两次运行的状态和报告都可在对应页签查看。策略挖掘自动生成新任务时也遵循这一规则。批量运行时，每份样本的任务均可单独重新提交。

平台默认同时运行 2 个任务，单独提交和批量提交共用队列。每个任务使用独立进程，名额用满后，新任务按提交顺序排队。可在启动时用 `python -m hscredit web --max-concurrent-jobs 4` 或 `launch(max_concurrent_jobs=4)` 调整并发数，支持 1 至 10。排队中、运行中和停止中的任务合计最多 10 个。

在 **任务管理** 可以分别查看进度和结果。点击某个任务的 **停止** 只影响该任务。排队任务会立即取消，运行中的任务会先显示「停止中」，计算进程及其子进程退出后显示「已停止」，随后下一个排队任务开始执行。

关闭网页不会停止任务；停止 Python 服务会停止未完成任务并保留配置。服务意外退出后，计算进程会随父服务退出，重启会把中断任务标为失败。停止中、排队中或运行中的数据集仍禁止原地修改和删除，确认停止后释放限制。旧的同步探索 API 保持兼容，网页探索改用可停止的任务接口。

探索中的直方图排除缺失与无穷值，类别分布显示前 30 类及其余合计，散点图最多固定种子抽取 3000 个有效点并标注有效样本量。训练、分箱和报告使用全部有效输入行，不使用图表抽样。

## 从探索到发布

**配置与结果。** 主页面选择必需的主样本、模型或分析字段，其余设置按用途打开弹窗。应用配置后再提交任务；启用自动生成的策略任务会在应用后触发。历史任务保留当时的数据版本和配置。

| 入口 | 作用范围与选择方式 |
| --- | --- |
| 配置样本 | 整个任务共用主样本。模型测试方式三选一；独立测试方式要求一个测试样本，其他评估样本及批量运行样本均可选、多选。 |
| 配置目标变量 | 标签定义方式单选，探索可选无标签。现有标签逐字段指定坏样本值；逾期口径要求字段、比较符和阈值；字典按条定义。缺失处理作用于所有标签；灰样本选项随定义方式出现。多口径训练可指定一个主标签。 |
| 配置运行参数 | 可使用默认值。模型分别设置训练验证、模型超参数、预测评分和评估输出。IV 阈值、搜索空间、PDO 等随相应功能显示。策略和三方测试分别设置分箱或树参数、报告统计维度和适用的输出选项。 |
| 配置分布统计 | 探索任务的分布格数和日期汇总频率，作用于所选字段，与目标标签定义独立。 |


**交叉分析。** 运行后同时展示所选字段及所有两两组合。交叉图可按分组标签筛选，三个字段可展开三维图。每对字段独立计算有效样本，不因第三个字段缺失而丢行；密度使用全量有效行，每幅散点图固定种子最多取 3000 行。三维图支持拖拽旋转，使用浏览器 WebGL。

**策略挖掘。** 在单变量或双变量页选好字段后自动生成结果。在多变量页选树类型，再选字段；二叉树使用数值字段，多叉树也支持类别分裂。需要修改策略时展开「手工调整节点分裂」，指定节点编号、字段以及数值阈值或多叉类别组。训练、测试与其他评估角色不能重复绑定同一数据集。

- 默认生成分箱表与分箱图。添加时间、分组或额外评估标签后，按对应维度增加趋势、多标签图；同时配置时可查看每个时期或组内的多标签对比。双变量并排查看两个字段，多变量逐行查看。
- 在分箱或树节点规则表中切换评估数据集，比较命中数、命中占比、坏率与 LIFT。勾选后可逐条加入规则集，或合并为一条「或」规则，名称可改。规则使用拟合时的实际边界，显示文本的四舍五入不改变命中结果。
- 在「规则集评估」修改名称和组合逻辑，拖拽或用上／下移调整顺序，再点击评估。单规则、组合效果与逐条累计命中分别展示。顺序分析按逐条拦截计算；最终组合则遵循所选的与／或逻辑。树报告与每份样本的置换报告在结果底部按实际 Excel 工作表预览，可下载原文件。

**模型构建。** 「模型实验配置」训练一个模型。「模型效果对比」可同时选多个模型，结果使用 `compare_models`。选中的模型逐行显示类名、模型名、描述及参数。点击该行的 **配置参数** 修改模型超参数，应用后可在参数列核对完整的参数名和值；较长的 JSON 悬停可展开查看。交叉验证、超参数搜索、评分和评估报告设置由本次对比共用，在 **配置运行参数** 中调整。未手选字段时，先用数据集推荐特征，没有推荐则使用非标签字段；业务标识及贷后字段应通过「字段选择」排除。默认分层留出 25%，可改用独立测试集，或关闭留出做训练样本内评估。训练和独立评估使用「目标变量」面板选定的主标签、额外标签与缺失策略。

可添加 IV 特征筛选、超参数搜索、概率转评分，以及「SHAP 与变量交互」。选择和预处理只在训练折拟合；每种模型均可下载，`model.joblib` 为训练交叉验证 AUC 最佳者。模型结果包含 ModelReport 指标、图和按标签的 Excel 报告。SHAP 需安装 `hscredit[explain]`，整体图使用 `plot_model_feature_importance`；训练后按数据集和行号使用 `plot_model_sample_shap`。经典模型展示其预处理和筛选后的实际模型输入，包括独热编码字段。

**发布与调用。** 在「PaaS 服务」点击「发布服务」，来源可选成功任务的模型／规则集制品、可信来源的 pickle 或 joblib 推理文件（包括 hscredit 的 `save_inference`），或手写规则 JSON。例如：

```json
[{"name":"低分","expression":"评分 < 500"},{"name":"高申请次数","expression":"申请次数 >= 6"}]
```

规则服务使用 `RuleSet` 和 `RulesClassifier`。发布后立即在同一 FastAPI 进程、同一监听地址提供预测接口；不需要为每个模型启动端口。复制首次显示的服务令牌，或在服务列表中轮换。每个服务的「文档与调试」给出必填字段、请求示例和 OpenAPI 下载。以下示例中的地址替换为平台实际的启动地址：

```python
import os
import requests

url = "http://127.0.0.1:8765/services/<服务ID>/predict"
headers = {"Authorization": "Bearer " + os.environ["RISK_SERVICE_TOKEN"]}
r = requests.post(url, headers=headers, json={"records": [{"评分": 480, "申请次数": 2}]}, timeout=15)
r.raise_for_status()
print(r.json()["predictions"])
```

每次支持 1–10000 行，输出顺序与输入一致。有概率输出时按 `classes` 的顺序返回；评分模型还可返回评分。服务预测与 `/services/<服务ID>/openapi.json` 默认允许任意来源跨域，跨域预检不需要令牌，实际请求必须携带该服务的 Bearer 令牌。平台管理接口仍使用原有的同源和平台鉴权。下线不删除制品；重启同一数据目录可继续使用服务。

**排查预测调用。** 在「PaaS 服务 → 已发布服务」点击对应服务的「调用记录」。可按调用时间倒序翻页、仅查看失败调用，或输入响应头 `X-Request-ID` 中的完整编号精确查询。打开详情可以核对原始请求体、实际响应体、HTTP 状态、耗时及应用层 HTTP 头。校验失败、令牌无效、服务下线的预测请求也会记录。请求和响应正文完整保存，非 UTF-8 正文以 Base64 展示。鉴权和 Cookie 等凭据头及敏感查询参数会隐藏。调用记录仅由平台管理接口提供。

新服务和已有服务均默认永久保存从启用此功能起产生的调用。在「调用记录 → 保存期限」可为当前服务选择永久或按天保留，天数以调用时间起算。缩短期限会立即清理超期历史，改回永久只保留尚未过期的记录。平台启动及运行期间每小时清理过期记录。日志存储于当前平台数据目录下的 `services/calls.sqlite3`，重启后仍可查询。

## 模型与报告约定

模型从 hscredit 公开导出表枚举，缺少可选依赖的模型保留并显示原因。安装 `hscredit[boost,net]` 可启用对应能力；TabPFN 还取决于上游权重、授权和硬件要求。单独的校准器和已拟合校准组合是变换或推理组件，训练请选概率校准模型。

所有正式报告直接调用 hscredit 能力，不另外生成 HTML 报告。模型图表使用 `roc_plot`、`ks_plot`、`lift_plot`、`confusion_matrix_plot`，支持网页预览与放大；交互 ROC 使用 hscredit 绘图结果中的曲线，重要性使用 `ModelReport` 输出。若预处理改变字段数量，重要性按编码后的字段展示，不冒充原始字段贡献。

默认最少一个箱、每箱最少一个样本，以保留统一样例中的低变异和高缺失字段；页面可调整约束，约束不可行时显示错误。模型报告数值特征的规则仅在训练集拟合，并通过公开 `rules` 参数复用；特征 PSI 使用 `feature_psi_params={"min_bin_size": 1}`，不改变评分 PSI 和既有调用的默认行为。

按标签进行分层随机切分，预处理在交叉验证的每个训练折内部拟合，留出集不参与调参或最佳模型选择。最佳模型按训练集交叉验证 AUC 选择。缺失标签默认按口径剔除，建模任务使用选定的二分类主标签。

经典模型和提升树采用数值中位数填补及标准化、类别众数填补和独热编码（每字段最多 50 类），支持未知类别，无穷值转缺失，全空列保留。神经网络使用 hscredit 自身预处理；评分卡在训练折内拟合 WOE；规则分类器在训练折内挖掘规则；概率评分卡与校准模型以逻辑回归为基础。导出包含预处理，可直接接收原始字段：

```python
import joblib

# 仅加载自己生成、可信来源的模型文件。
model = joblib.load("model.joblib")
probability = model.predict_proba(new_data)[:, 1]  # 页面所选坏样本的概率
```

搜索空间示例（与模型配置参数同名）：

```json
{
  "logistic": {"C": [0.01, 0.1, 1, 10]},
  "random_forest": {"n_estimators": [100, 200], "max_depth": [3, 6, 10]}
}
```

策略规则按所选数据集统计命中率和 LIFT，训练集指标需结合独立评估集判断。三方测试使用严格报告模式，必需章节失败时任务显示失败。分析结果中的摘要表每章节最多预览 2000 行。Excel 阅读器可逐页查看完整工作表，通过 **跳至章节** 定位长报告中的标题。下载文件保留 Excel 原始排版和条件格式。

## 主题与运行目录

代码编辑器会根据光标位置自动提示，也可以按 `Ctrl+Space` 调出候选。模型搜索空间先提示已选模型，再提示该模型支持的参数，例如 `{"logistic":{"C":[0.1,1]}}`。补全新的参数键时会带入推荐候选值，可继续修改。字段加工可引用当前数据集、前序加工字段和函数。规则表达式使用当前字段，多叉树类别组提示分裂字段的示例取值。手写 RuleSet 可在“字段提示来源”切换参考数据集，服务调试则使用已发布服务的输入字段。

平台使用与天枢决策引擎相同的 Monaco Editor 编辑表达式和 JSON。JSON 输入支持行号、语法错误标记和“格式化”。字段加工中可按 `Ctrl+Enter`（macOS 使用 `⌘+Enter`）解析表达式并回显到配置面板。编辑器随平台离线分发，打开后会实时跟随主题预览、取消和系统明暗切换。

页面设计与主题规范参考“观星”工作台，采用 Vue 3 + Element Plus + ECharts。按钮、输入框、标签、卡片、弹窗、抽屉及滚动条统一直角；普通输入框和按钮高 34px，顶部控件高 30px。单行表头高 34px，数据行高 36px，多行内容按需增高。表格采用主题色表头、交替行底色和上下边线，宽表在容器内横向滚动。阿里妈妈方圆体随包离线分发，字体版权归淘宝（中国）软件有限公司，许可见前端资源中的 `fonts/AlimamaFangYuanTiVF-LICENSE.txt`。

主题配置支持 12 个命名预设、自定义纯色或二至三色渐变、线性/径向渐变、方向设置、浅色/深色/跟随系统、顶部/左侧导航、深浅菜单、折叠与固定导航、表格滚动和色弱辅助。点选立即预览，取消、关闭或按 Esc 恢复原设置；点击“保存主题”后保存在当前浏览器。旧版配色偏好继续有效，新浏览器默认使用主题蓝和随页面滚动。表格滚动设置同时作用于数据预览、任务列表和报告表格。

模块名称直接显示在 header 面包屑首层，内容区不重复显示模块标题或单页页签；有实际分组的业务页签保留。在“数据资产”标题行右侧可加载 hscredit 示例或导入数据集，任务刷新入口位于 header，数据说明通过“数据说明”按需查看。main 始终铺满侧栏之外的可用宽度，旧版居中定宽设置自动迁移为铺满。左侧导航参照天枢：拖拽右边界可在 64–320px 内调宽，低于 168px 时只显示图标；底部按钮折叠或恢复上次展开宽度，双击边界恢复 220px，方向键微调宽度。设置保存在当前浏览器，窄屏展开导航时以浮层显示。

界面、弹出层和交互图表共用语义颜色；系统明暗模式变化时，已显示的图表同步更新。按钮文字根据实际配色选择对比色，必要时为渐变增加暗色遮罩。成功、警告和失败使用独立状态色。导出的报告图片保留原始绘图颜色，网页主题不会改变报告内容；色弱辅助不是完整无障碍合规声明。

默认数据目录为 `~/.hscredit/platform`，包括 Parquet 数据集、JSON 任务清单和报告文件。一个目录只允许一个运行实例。目录内包含原始数据，请按业务要求管理；平台不把数据传给在线演示站。单文件上传上限 100 MB，单个数据集最多 200 万行、2000 列，单任务最多 200 个特征，队列最多 10 个任务。当前版本面向本机单用户研发，无账户权限体系和分布式任务执行。

默认仅允许本机访问。如果需要局域网监听，显式设置至少 16 位的 `token`，或通过环境变量 `HSCREDIT_PLATFORM_TOKEN` 配合 `--host 0.0.0.0`。访问令牌位于启动链接的 fragment，页面放入当前会话存储并用于请求鉴权。共享部署应通过 HTTPS 反向代理提供服务。

### 查看和覆盖底层参数

打开模块的 **配置运行参数**（数据探索中为 **配置分布统计**），弹窗优先显示当前任务的**常用参数**。每行直接给出作用说明，配置控件下方列出默认值。切换**全部参数**可查看完整目录，也可直接搜索参数名或说明、按分组筛选。**已调整**列出当前草稿中偏离默认值的设置和显式底层覆盖值，点击**应用配置**生效。更换分箱方法后，表中会显示该算法专属的参数。多模型对比时，每个模型的构造和拟合参数在该模型行内编辑。

底层值按 JSON 类型填写。例如，字段概况的 `percentiles` 填 `[0.25, 0.5, 0.75]`，随机森林的 `bootstrap` 填 `false`，模型拟合的 `sample_weight` 可填带引号的数值字段名。权重跟随标签过滤、训练集划分及交叉验证折同步取行。也可以点 **添加自定义参数**，选择用途并输入参数名和值。清空或删除覆盖值会恢复默认行为，显式的 `null` 会原样提交。

任务配置中的 `model_params`、`model_fit_params` 分别按模型保存构造和拟合参数，`library_params` 按底层调用保存分析和报告参数。例如，`library_params.model_excel.with_plots` 控制模型 Excel 报告内的图表。任务中心的 **重新配置** 可以沿用这些值。

## 本地开发与热更新

在仓库根目录首次安装开发所需依赖。

```powershell
python -m pip install -e ".[web]"
npm.cmd --prefix web ci
```

打开两个 PowerShell 终端，工作目录都设为仓库根目录。在第一个终端启动 API，监听整个 `hscredit` 包里的 Python 源码。

```powershell
python -m uvicorn hscredit.web.dev:create_dev_app --factory --reload --reload-dir hscredit --host 127.0.0.1 --port 8765
```

在第二个终端启动页面。

```powershell
npm.cmd --prefix web run dev -- --open
```

使用 Vite 终端输出的页面地址，默认是 `http://127.0.0.1:5173/`。保存 Vue、JS 或 CSS 后页面自动更新。保存 Python 源码后，API 进程重启，开发页会在服务就绪后刷新并重新读取参数目录。已排队及运行中的任务会随 API 重启而中止，已落盘的配置和结果保留。分别在两个终端按 Ctrl+C 可停止开发服务。

开发服务默认复用普通启动时的数据目录。需要独立工作区时，在后端终端设置 `$env:HSCREDIT_PLATFORM_DATA_DIR`。若设置了 `HSCREDIT_PLATFORM_TOKEN`，首次访问开发页面时在地址后加 `#token=你的令牌`。

发布随包分发的页面时，在仓库根目录运行 `npm.cmd --prefix web run build`，资源会写入 `hscredit/resources/platform`。前端测试用 `npm.cmd --prefix web test`，后端测试用 `python -m pytest tests/test_platform -q`。


平台业务验收使用 `hscredit_dataset(columns=...)` 读取所需字段。探索核对全量样本计数；策略、模型和发布链路固定抽取 6000 行后，按授信时间划为训练、测试、其他评估样本。验收检查有效标签、分箱命中、手工改树、报告指标、SHAP、导出与在线预测的一致性。为避免普通单元测试触发数据下载，此组测试显式启用；需要 platform、dev、explain 依赖。

```powershell
$env:HSCREDIT_RUN_DATASET_TESTS = "1"
python -m pytest tests/test_platform/test_dataset_acceptance.py -q
```
