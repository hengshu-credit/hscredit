# 规则置换通过率口径与验证

## 固定申请母集与旧策略

`data` 是本次分析的申请母集，`N = len(data)`；`sample_survival_rate = s` 是它占全量申请的前置幸存比例。
前置筛选不随本次策略调整改变。分母等价于 `N / s`，不取整、不按逾期标签剔灰。

| 输入范围 | 幸存比例 | 旧策略标记 | 可以验证的效果 |
|---|---|---|---|
| 全量申请 | 1 | 实际旧审批标记 | 完整置入、置出 |
| 前置筛选后申请 | 前置通过比例 | 筛选后样本的旧审批标记 | 还原全量口径的完整置换 |
| 仅旧策略通过样本 | 旧策略全量通过率 | 全 True | 原通过客群内的新增拒绝；缺少拒绝样本不能估计置入量 |

`original_pass` 支持列名、布尔或 0/1 Series/ndarray/list。Series 按索引对齐，数组按位置对应；
重复索引的 Series 必须与输入索引完全一致。缺失值、非法值和长度不匹配均报错。
`rules_base` 是始终拒绝规则，不得命中标为旧策略通过的样本。
置出规则只在旧通过客群执行，置入规则只在旧拒绝且未命中基础拒绝的客群执行。

未传 `original_pass` 时保留历史分组兼容性：基础拒绝、置出、再从剩余样本识别置入。
旧通过集合由 `IN-IN | IN-OUT` 反推。这是模拟旧策略，不是实际历史审批；
比较多个置入方案时必须传入固定旧审批标记，避免方案同时改变旧基准。
三个规则集均为空时，旧策略与新策略一致。

## 公式与单位

记 K 为 IN-IN、O 为 IN-OUT、I 为 OUT-IN、R 为 OUT-OUT，四组互斥且覆盖输入母集。

```text
旧策略通过率 = s × (|K| + |O|) / N
新策略通过率 = s × (|K| + |I|) / N
净变化       = s × (|I| − |O|) / N
相对变化     = 净变化 / 旧策略通过率
```

保留已有数值单位：`通过率`、`生产通过率`、`通过率(绝对值)` 和汇总中的通过率前后值为 0–100；
`通过率变化`、汇总通过率的 `绝对变化` 为百分点；相对值为小数，例如 0.1 表示增长 10%。
不要对已经是 0–100 的数值直接应用 Excel 的百分比格式。
旧基线为零、新值非零时相对变化为 NaN；前后均为零时为 0。
风险率仍使用 0–1，不能给整个混合指标列应用同一种百分比格式。

## 明细、规则模式与执行并行

- `independent`：同阶段每条规则都相对同一父客群计算，命中可能重叠，明细不可相加；阶段合计按并集去重。
- `sequential`：后一条规则在上一条之后的剩余客群评估；置出逐步减人，置入逐步加人。人数与百分点增量可相加，相对变化不可直接相加。
- `n_jobs` / `parallel_backend` 仅控制代码执行，不能改变行顺序、任何指标或最终策略结论。
- IN-OUT 阶段从完整旧通过集合开始；OUT-IN 阶段从保留通过集合开始。
- `原策略通过` 显示完整旧通过集合；`ALL-IN置换` 与 `swap_result` 比较完整旧策略和新策略。
- `全量样本` 是输入母集，其生产口径占比为 `s × 100`，并不意味着全部已获最终审批通过。

## 剔灰与风险样本

规则在完整输入母集上执行。`决策样本数`、`决策样本占比`、阶段前后人数和通过率不受标签影响。
`del_grey=True` 只让实际表现无效的样本退出风险统计；OUT-IN 使用预测表现，不因缺少实际标签而丢失。
`样本总数` 为该行有效风险样本数，可能小于 `决策样本数`。多标签分别保留风险统计，但共享审批统计。
金额参数、风险上浮参数、展示逆序均不得改变审批通过率。
