# hscredit 项目路线图

## 产品定位

hscredit（衡枢真信）将自己定位为金融分析库中信贷风控功能最全、端到端流程最完整、Excel 写入功能最完善、分析可视化体验最好的全流程工具。它面向数百亿元放款规模的信贷平台，为策略、模型和贷后团队提供共用的风控研发脚手架。

以调整一条授信准入规则为例，分析师可以从放款订单定义逾期标签，按月份和客群查看风险分布，通过分箱或规则树找到候选切点，再回测新旧策略对通过率、放款金额和坏账率的影响。同一套工具也能训练和解释评分模型，导出计分逻辑并跟踪上线后的分数漂移。策略评审所需的图表、命中明细和客群对比可以直接写入同一份 Excel 工作簿。[功能与示例](showcase.md)

## 三种使用入口

| 入口 | 如何开展分析 |
| --- | --- |
| Python API | 在 Notebook 中用 pandas 和 scikit-learn 风格的接口串联分箱、筛选、建模和回测。团队可以自定义损失函数与评估指标，将验证过的流程接入自己的批处理任务。[API 参考](api/index.rst) |
| AI 大模型 Skills | 用自然语言描述分析目标，例如“按授信月份比较新旧规则的通过率和坏账率，并生成 Excel”。Agent 通过 Skills 调用 hscredit 的分析接口，交付结果表、图形或工作簿。[Agent Skills 指南](skills.md) |
| 风控平台可视化界面 | 安装平台扩展后，运行 `python -m hscredit web --demo` 即可在浏览器打开示例数据，比较变量分布、调整规则、评估模型并下载报告。[风控平台指南](platform.md) |

三种入口让不同经验的团队都能开箱即用。业务人员可以从示例数据和网页操作入手，分析师可以把同一业务问题交给 Skills，开发者则可以直接组合底层 API。基础分析沿用 NumPy、pandas 和 scikit-learn 生态，Boosting、神经网络、调参和风控平台按需安装。[安装指南](installation.md)

## 可视化与 Excel 交付

- **可视化分析**按业务问题选图。分箱坏率图帮助判断风险切点，Vintage 曲线揭示不同放款批次的逾期演变，KS、Lift 和 SHAP 图分别展示模型的区分度、高风险客群的集中程度和单笔评分原因。[可视化 API](api/viz.rst)
- **Excel 写入**覆盖从明细到评审报告的完整编排。分析师可以把多级表头、条件格式、原生图表、图片和原生透视表写入多个工作表，用目录链接串联结论与明细。业务方拿到工作簿后，仍可自行切换客群、筛选数据并复核结论。[Excel API](api/excel.rst)

## 后续建设方向

- **策略迭代与贷后监控**。围绕审批偏差、规则效果衰减和客群迁移，深化策略回测与贷后表现的联动分析。
- **结果追溯**。加强从样本、标签、变量到模型、规则和报告的版本关联，便于团队复核策略调整依据。
- **多入口协作**。扩大可通过 Skills 和风控平台执行的分析任务，让更多 Python 工作流可以用自然语言或网页操作完成。
