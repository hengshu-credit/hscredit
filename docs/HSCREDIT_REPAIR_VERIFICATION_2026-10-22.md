## 三、扩大回归中追加修复

1. **SHAP 特征聚类与聚类图**：Pandas 返回的相关矩阵可能只读，修改对角线前创建可写副本。模型解释报告及图形回归通过。
2. **逻辑回归 WOE 符号调整**：使用整列替换，允许整数输入安全转换为浮点；避免 Pandas 3 的 iloc 原地赋值类型错误。评分卡 Pipeline 和模型语义回归通过。
3. **冻结监控基准的混合类别**：未知类别判断使用 object 语义，避免 Arrow 字符串强制转换整数/元组类别；旧制品迁移、重新拟合及缺失比例检查通过。
4. **多标签逾期报告拼接**：明确保留分箱列的元组键，再与普通预测汇总列组合；消除不同层级列索引的合并错误，串并行真实数据结果一致。
5. **旧 NGBoost 与 NumPy 2 的自然梯度不兼容**：可选依赖下界提高到已经实测的 `ngboost>=0.5.11`；原生自定义损失、模型训练和权重语义复测通过。
6. **分箱标签测试的存储类型假设**：接受 Pandas 2 的 object 字符串列和 Pandas 3 的字符串扩展列，仍验证实际标签与串并行结果一致。

环境验证脚本现在检查实际子模块导入、项目依赖版本、已安装 Boosting 版本及源码/安装元数据一致性，避免“顶层 import 成功”被误当成完整环境可用。
