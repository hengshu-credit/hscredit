# 类别分箱最小样本量约束修复设计

## 背景

类别特征会先按坏样本率排序并编码为连续数值，再由具体分箱算法生成数值切分点，最后还原为 `List[List]` 类别规则。当前还原流程在生成统计表后直接校验 `min_bin_size`，但没有统一调整仍可合并的小箱。

在 `examples/hscredit_yyp.xlsx` 中，`商品类别` 使用 `min_bin_size=0.01` 时，`uniform` 生成样本数为 `4`、`2`、`20`、`141`、`803` 的五个普通箱。总样本数为 970，公共逻辑按现有语义计算最小箱样本数为 9。前两个小箱本可与相邻类别合并，但当前实现直接抛出 `ValueError`。`genetic` 存在相同问题。

## 参数语义

保持现有语义不变：

- `0 < min_bin_size < 1`：按总样本数比例计算，沿用现有向下取整逻辑并保证至少为 1。
- `min_bin_size >= 1`：按绝对样本数计算；`min_bin_size=1` 表示每箱至少 1 条样本。

本次不修改参数合法性校验、比例换算方式或数值型分箱行为。

## 方案

在 `BaseBinning._finalize_categorical_fit` 中，将具体算法给出的数值切分点规范化并补足可行的 `min_n_bins` 后、还原类别组之前，调用 `_adjust_splits_for_bin_size_constraints` 的类别专用约束修复路径。

调整器接收类别有序编码、当前切分点以及由公共方法计算的最小和最大箱样本数。每个类别是不可拆分的原子单元；当前规则不满足约束时，使用有序动态规划搜索连续类别分区：

1. 箱数必须位于 `min_n_bins` 与 `max_n_bins` 之间，且不超过可用类别数。
2. 每个连续分区同时满足 `min_bin_size` 和可选的 `max_bin_size`。
3. 当前规则已经可行时原样返回；需要调整时优先保持原箱数，其次最少改变已有边界，再按边界移动距离和样本均衡度确定唯一结果。
4. 动态规划允许一次重排多个边界，避免单步贪心在可行解需要中间等价移动时误判不可行。
5. 调整完成后还原类别组、重算统计表，再由 `_validate_categorical_constraints` 执行最终硬校验。
6. 如果不存在满足全部样本量条件的连续分区，例如单个原子类别超过 `max_bin_size`，保留清晰的 `ValueError`，不静默放宽参数。

动态规划使用前缀样本量和单调滑动窗口维护每个终点的合法前驱区间，转移复杂度随箱数上限和类别数线性增长，避免高基数类别的平方级枚举。数值分箱继续使用原有贪心调整逻辑；动态规划仅由类别最终化流程显式开启，因此不会改变数值型分箱行为。

## 兼容性边界

- `OptimalBinning` 与所有直接分箱器共享同一修复。
- 不改变 `min_bin_size=1` 的绝对样本数语义。
- 不改变缺失箱、特殊值箱和未知类别的保留索引。
- 不改写用户显式传入且要求严格执行的类别规则。
- 只有样本量约束需要调整时才改变算法产生的类别边界。

## 测试

先添加失败回归测试，再修改生产代码：

1. 构造含多个稀有类别的数据，验证 `uniform` 会合并可行小箱，所有普通箱均满足 `min_bin_size`。
2. 对同一数据验证 `genetic` 的可行小箱也会被合并。
3. 验证 `min_bin_size=1` 仍表示至少 1 条样本，而不是 100% 比例。
4. 保留不可行 `max_bin_size` 场景的明确报错。
5. 验证固定箱数时可以把合并小箱释放的边界用于拆分另一个箱。
6. 验证需要连续移动多个边界时，最终分区同时满足最小和最大样本量。
7. 运行类别分箱相关测试和完整非慢速、非集成测试。
8. 使用 `examples/hscredit_yyp.xlsx`、`商品类别` 和 `target_demo=(MOB1 > 3)` 遍历 `OptimalBinning.VALID_METHODS`，确认全部方法成功拟合且普通箱满足配置的最小样本数。
