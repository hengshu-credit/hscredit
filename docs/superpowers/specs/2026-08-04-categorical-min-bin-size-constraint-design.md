# 类别分箱最小样本量约束修复设计

## 背景

类别特征会先按坏样本率排序并编码为连续数值，再由具体分箱算法生成数值切分点，最后还原为 `List[List]` 类别规则。当前还原流程在生成统计表后直接校验 `min_bin_size`，但没有统一调整仍可合并的小箱。

在 `examples/hscredit_yyp.xlsx` 中，`商品类别` 使用 `min_bin_size=0.01` 时，`uniform` 生成样本数为 `4`、`2`、`20`、`141`、`803` 的五个普通箱。总样本数为 970，公共逻辑按现有语义计算最小箱样本数为 9。前两个小箱本可与相邻类别合并，但当前实现直接抛出 `ValueError`。`genetic` 存在相同问题。

## 参数语义

保持现有语义不变：

- `0 < min_bin_size < 1`：按总样本数比例计算，沿用现有向下取整逻辑并保证至少为 1。
- `min_bin_size >= 1`：按绝对样本数计算；`min_bin_size=1` 表示每箱至少 1 条样本。

本次不修改参数合法性校验、比例换算方式或数值型分箱行为。

## 方案

在 `BaseBinning._finalize_categorical_fit` 中，将具体算法给出的数值切分点规范化并补足可行的 `min_n_bins` 后、还原类别组之前，调用已有的 `_adjust_splits_for_bin_size_constraints`。

调整器接收类别有序编码、目标变量、当前切分点以及由公共方法计算的最小和最大箱样本数。它只在约束不满足时调整边界：

1. 小于 `min_bin_size` 的箱与相邻坏样本率最接近的箱合并。
2. 合并不得使普通箱数低于 `min_n_bins`。
3. 设置 `max_bin_size` 时，在不超过 `max_n_bins` 且类别边界可拆分的情况下增加切分点。
4. 调整完成后还原类别组、重算统计表，再由 `_validate_categorical_constraints` 执行最终硬校验。
5. 如果约束组合不可行，例如已达到 `min_n_bins` 仍有小箱，或单个原子类别超过 `max_bin_size`，保留清晰的 `ValueError`，不静默放宽参数。

该方案复用现有数值边界调整逻辑，保留各具体算法的初始边界和类别排序，不新增第二套类别合并实现。

## 兼容性边界

- `OptimalBinning` 与所有直接分箱器共享同一修复。
- 不改变 `min_bin_size=1` 的绝对样本数语义。
- 不改变缺失箱、特殊值箱和未知类别的保留索引。
- 不改写用户显式传入且要求严格执行的类别规则。
- 只有样本量约束需要调整时才改变算法产生的类别边界。

## 测试

先添加失败回归测试，再修改生产代码：

1. 构造含多个稀有类别的数据，验证 `uniform` 会合并可行小箱，所有普通箱均满足 `min_bin_size`。
2. 对同一数据验证 `genetic` 的可行小箱也会被合并。
3. 验证 `min_bin_size=1` 仍表示至少 1 条样本，而不是 100% 比例。
4. 保留不可行 `max_bin_size` 场景的明确报错。
5. 运行类别分箱相关测试和完整非慢速、非集成测试。
6. 使用 `examples/hscredit_yyp.xlsx`、`商品类别` 和 `target_demo=(MOB1 > 3)` 遍历 `OptimalBinning.VALID_METHODS`，确认全部方法成功拟合且普通箱满足配置的最小样本数。
