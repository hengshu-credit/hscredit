# 类别变量方法化分箱修复设计

## 背景

`examples/hscredit_hsk.xlsx` 包含大量类别变量。当前 `OptimalBinning` 虽然能够在默认配置下完成拟合和转换，但类别变量存在以下系统性问题：

- `OptimalBinning` 在底层方法完成拟合后，统一调用坏样本率合并逻辑，导致用户选择的 `method` 对类别变量失去实际意义。
- 17 个直接分箱器的类别处理不一致，部分方法不执行 `max_n_bins` 等约束，部分方法的 `n_bins_`、分箱表和转换结果不一致。
- `max_bin_size`、`min_bad_rate`、`monotonic`、`cat_cutoff` 等参数在部分或全部类别路径中被忽略。
- 自定义类别分箱缺少完整校验，未覆盖类别、重复类别和空箱可能被静默接受。
- 未知类别和未覆盖类别会因为分箱索引数组初始化为 0 而错误进入第 0 箱。
- 类别匹配使用字符串转换，原生数值 `1` 和字符串 `"1"` 会被错误视为同一类别。
- pandas 可空布尔类型识别不完整，预分箱和规则导入导出的类别元数据也可能丢失。

本次修复需要保留各分箱方法自己的切分目标、停止条件和合并标准，同时统一类别排序、规则匹配和规则生命周期。

## 目标

1. 类别变量默认按训练集坏样本率生成稳定的有序编码。
2. 用户可以显式提供类别顺序，或提供排序函数。
3. 有序编码进入用户选择的分箱器原生数值算法；最终结果再还原为 `List[List]` 类别组。
4. 17 种直接分箱器与 `OptimalBinning` 使用相同的类别排序适配流程，但不共享一个统一的类别合并算法。
5. 自定义分箱、缺失值、特殊值、未知类别、约束参数和规则导入导出具有明确且一致的行为。
6. 使用 `hscredit_hsk.xlsx` 和自动化测试完成真实数据验证。

## 非目标

- 不新增公开的 `CategoricalBinning` 分箱器。
- 不改变数值变量现有方法选择语义。
- 不用一个统一的坏样本率合并器覆盖所有类别变量方法。
- 不自动把所有低基数数值字段识别成类别变量；数值编码类别仍通过 `cat_cutoff` 显式启用。

## 公开接口

### category_order

在 `BaseBinning` 和所有公开分箱器中增加 `category_order` 参数：

```python
category_order: Optional[
    Union[
        Dict[str, Sequence],
        Callable[[str, pd.Series, pd.Series], Sequence],
    ]
] = None
```

- `None`：按每个类别的训练集坏样本率升序排列。
- `Dict[str, Sequence]`：为指定特征提供完整类别顺序。
- `Callable`：接收特征名、原始特征和目标变量，返回完整类别顺序。
- 字典未包含的特征继续使用默认坏样本率排序。
- 用户顺序必须完整覆盖训练集全部非缺失、非特殊类别，且每个类别只能出现一次。
- 坏样本率相同时按训练集首次出现顺序稳定排序。

`category_order` 只决定类别的相对顺序，不决定分箱边界。分箱边界由所选 `method` 决定。

### handle_unknown

增加与编码器一致的未知类别策略：

```python
handle_unknown: str = "value"
```

- `"value"`：未知类别进入索引 `-3`，分箱标签为 `unknown`，WOE 为 `0.0`。
- `"error"`：转换时发现未知类别，抛出包含特征名和未知值的中文 `ValueError`。

构造器校验仅接受上述值。

## 自动类别分箱流程

每个类别特征按以下流程处理：

1. 分离普通类别、缺失值和 `special_codes`。
2. 使用坏样本率或用户提供的顺序得到完整类别序列。
3. 按顺序映射为连续整数 `0..n-1`，保存正向和反向映射；匹配保留原始类型，不使用 `astype(str)`。
4. 将编码后的训练样本作为数值特征，强制走当前分箱器的数值分箱路径，避免再次被 `cat_cutoff` 识别为类别。
5. 复用所选方法现有的目标函数、停止条件、约束处理和切分点计算。
6. 将每个类别编码应用到所得数值切分点，将同一数值箱中的类别还原成一个类别组。
7. 去除空组，按实际分箱索引重编号，并同步写入 `_cat_bins_`、`splits_`、`n_bins_` 和 `bin_tables_`。
8. 缺失值、特殊值和未知类别使用保留索引 `-1`、`-2`、`-3`，不计入普通箱数。

这个适配过程保留方法差异：

- `uniform` 对有序编码等宽切分。
- `quantile` 按编码后的样本分布等频切分。
- `tree`、`cart` 使用决策树目标选择切点。
- `chi` 使用卡方合并。
- `best_ks` 使用 KS 标准。
- `best_iv`、`or_tools`、`cp_sat`、`genetic` 使用各自的 IV 或优化目标。
- `mdlp` 使用 MDL 停止准则。
- `kmeans` 对有序编码聚类。
- `monotonic`、`smooth`、`kernel_density`、`best_lift`、`target_bad_rate` 继续复用各自数值实现。

`OptimalBinning` 删除自动调用 `_regroup_categorical_features()` 覆盖底层结果的行为。

## 自定义类别分箱

类别自定义规则使用 `List[List]`：

```python
{"feature": [["c1", "c2"], ["c3"], [np.nan]]}
{"feature": [["c1", "c2"], ["c3"], ["c4", np.nan]]}
```

同时支持 `np.nan`、`None` 和 `pd.NA` 作为缺失标记。缺失标记可以单独成箱，也可以和普通类别合箱。

校验规则：

- 外层必须是非空列表，每个普通箱必须是非空列表。
- 同一普通类别不得出现在多个箱中。
- 缺失标记最多出现一次。
- 训练集中观察到的全部非缺失、非特殊类别必须被覆盖。
- 显式包含缺失标记时，缺失值使用该普通箱索引，不再使用 `-1`。
- 未显式包含缺失标记且 `missing_separate=True` 时，缺失值进入 `-1`。
- 未显式包含缺失标记、`missing_separate=False` 且训练数据存在缺失时，抛出中文 `ValueError`，要求用户指定缺失值所属箱。
- `strict_user_splits=True` 完整保留用户箱边界。
- `strict_user_splits=False` 允许所选方法在用户箱之间继续合并，但不得拆散用户已经定义的类别组。
- `user_splits` 对某个特征生效时，其优先级高于 `category_order`。

旧的扁平字符串列表格式继续保留兼容读取，但新代码和导出格式统一使用 `List[List]`。

## 约束与参数校验

构造器统一校验：

- `min_n_bins >= 1`。
- `max_n_bins >= 1`。
- `min_n_bins <= max_n_bins`。
- 比例形式的 `min_bin_size`、`max_bin_size` 位于 `(0, 1]`。
- 绝对数量形式的箱大小参数为正数。
- `min_bad_rate` 位于 `[0, 1]`。
- `cat_cutoff` 为正数；小于 1 时表示唯一值比例，大于等于 1 时表示唯一值数量。
- `woe_clip` 必须为正数。
- `monotonic` 必须为支持的枚举值或布尔值。
- `handle_unknown` 必须为 `"value"` 或 `"error"`。

类别适配器不增加统一的二次合并。约束由所选方法的数值路径执行；适配器只在还原类别组后验证最终结果。若方法无法在不拆分类别的前提下满足约束，例如单一类别样本占比已经超过 `max_bin_size`，必须抛出说明特征、参数和实际值的中文错误，不能静默忽略。

`cat_cutoff` 必须传递到全部 17 种方法、预分箱器和直接分箱器。pandas `BooleanDtype` 与原生布尔类型均识别为类别变量。

## 规则应用与生命周期

类别匹配使用缺失感知、类型安全的比较：

- 数值 `1` 与字符串 `"1"` 是不同类别。
- `np.nan`、`None`、`pd.NA` 统一识别为缺失标记。
- 普通分箱索引数组先初始化为未知索引 `-3`，只有匹配成功后才写入普通箱索引。
- 特殊值优先级高于普通类别，显式缺失组优先级高于 `missing_separate`。

`export_rules()`、`import_rules()`、`update()` 和预分箱复制必须保存：

- 原始类别值及其类型；
- 类别组顺序；
- 缺失值所在组；
- 类别排序映射；
- `n_bins_`、`splits_` 与 `_cat_bins_` 的一致性。

规则导入后可以立即执行 `transform(metric="indices" | "bins" | "woe")`。如果导入文件不包含训练统计，普通箱和未知箱的 WOE 使用中性值 `0.0`，并保持现有兼容行为。

## 实现结构

新增内部模块 `hscredit/core/binning/_categorical.py`，包含：

- 缺失标记检测与类型安全类别比较；
- 类别顺序解析和校验；
- 类别与有序编码的双向映射；
- 自定义 `List[List]` 规则规范化和校验；
- 数值切分结果到类别组的还原；
- 未知类别掩码和诊断信息。

`BaseBinning` 提供受保护的适配入口和公共参数校验。各直接分箱器只需要在单特征拟合时：

1. 检测类别特征；
2. 调用适配器生成数值编码；
3. 复用本类数值拟合函数；
4. 调用适配器还原并记录类别规则。

若现有分箱器尚未把单特征数值拟合拆成可复用函数，先做不改变数值行为的小范围提取，再接入类别适配器。

## 测试设计

### 单元测试

- 默认坏样本率排序及相同坏样本率的稳定顺序。
- 字典顺序和 callable 顺序。
- 用户顺序缺失、重复或包含未知类别时报中文错误。
- 原生数值 `1` 与字符串 `"1"` 不混淆。
- pandas `BooleanDtype` 识别为类别变量。
- 两种缺失值自定义规则：`[np.nan]` 和 `["c4", np.nan]`。
- `None`、`pd.NA` 缺失标记。
- 空箱、重复类别、未覆盖类别和重复缺失标记校验。
- 未知类别的 `-3`、`unknown`、WOE `0.0` 及 `handle_unknown="error"`。
- 参数合法边界、非法配置和不可满足约束。
- `export_rules()` / `import_rules()` / `update()` 往返一致。
- 预分箱保留 `_cat_bins_` 和排序映射。

### 方法差异测试

构造包含不同类别频率和坏样本率的数据，逐一验证 17 种方法：

- 能完成类别拟合和三种 metric 转换；
- 普通箱数、分箱表和规则一致；
- 方法结果来自各自数值算法，而不是统一合并函数；
- 至少在具有区分度的数据上，等宽、等频、树、卡方、KS、IV、MDLP 等方法产生符合各自准则的不同边界；
- `max_n_bins`、`min_bin_size`、`max_bin_size`、`min_bad_rate` 和 `monotonic` 的可行配置生效，不可行配置明确报错。

### 真实数据验证

对 `examples/hscredit_hsk.xlsx`：

- 验证 3381 行数据和目标变量分布不被修改。
- 默认类型推断验证文本类别字段。
- 设置 `cat_cutoff` 后验证数值编码状态字段按类别处理。
- 对 17 种方法运行完整拟合、`indices`、`bins`、`woe` 转换。
- 验证每列转换行数一致、无静默未匹配、分箱计数等于原始样本数。
- 验证自动规则和自定义规则导出导入后结果一致。
- 验证两种缺失值自定义分组在真实缺失数据上的行为。

最后运行 `pytest tests/test_binning -q`，并视修改影响运行非慢速、非集成测试集。

## 兼容性与迁移

- 默认 `category_order=None` 不要求现有调用方增加参数。
- 类别变量的结果可能与旧版本不同，因为旧版本的统一后处理和静默第 0 箱行为属于本次明确修复的缺陷。
- 数值编码类别仍需显式设置 `cat_cutoff`，避免改变连续数值变量的默认语义。
- 旧的扁平类别规则可以导入，但导出统一为类型安全的 `List[List]`。
- 变更日志需要说明类别分箱现在真正遵循所选 `method`，以及未知类别新增 `-3` 语义。

## 验收标准

1. 全部 17 种方法对类别变量使用各自算法，不再统一调用 `_regroup_categorical_features()`。
2. 用户可通过坏样本率默认排序、显式列表或 callable 控制类别顺序。
3. 两种用户要求的缺失值分组格式均可拟合、转换和规则往返。
4. 未知类别、重复类别、未覆盖类别和不可满足约束不再静默落入第 0 箱或被忽略。
5. 所有公开约束参数在类别路径中有明确、可测试的效果。
6. `hscredit_hsk.xlsx` 的 17 方法验证通过，自动化回归测试通过。
