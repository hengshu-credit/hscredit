# `bin_2d_plot` 二维合并箱彩色轮廓设计

## 背景

`bin_2d_plot` 的样本占比、坏样本率、LIFT、坏账改善和风险拒绝比子图目前只展示预分箱网格及指标值。虽然 `OptimalBinning2D.solution_` 已记录每个预分箱格子所属的最终二维箱，但组合图没有使用该映射，用户无法从图中辨认哪些格子已被合并为同一箱。

## 目标

在上述五个热力图上叠加最终二维箱的彩色外轮廓，使同一最终箱包含的全部格子被一个整体边框圈住。

必须满足：

- 新增彩色边框只沿最终二维箱的外轮廓绘制。
- 同一最终箱内部相邻格子之间不绘制彩色边框。
- 每个最终箱从统一连续色阶中取得一种颜色。
- 同一最终箱在五个指标子图中的边框颜色保持一致。
- 保留现有热力图底色、白色格线、数值标注、标题、坐标轴和布局。
- 不新增箱编号、图例、文字或其他视觉元素。
- 缺失值行和缺失值列按照 `solution_` 中的最终箱归属正常参与轮廓绘制。

## 方案选择

采用“按最终箱提取边界线段”的方案。对显示方向校正后的 `solution_` 逐格检查四条边：当相邻位置超出矩阵边界，或相邻格子属于其他最终箱时，该边属于当前最终箱的外轮廓；相邻格子属于同一箱时不生成该边。

不采用以下方案：

- 逐格绘制彩色矩形：会在同箱内部产生彩色分隔线，不符合整体框选要求。
- 使用 `contour`：分类矩阵的插值轮廓不能保证始终严格贴合离散网格，尤其不适合凹形或 L 形箱。

## 代码结构

在 `hscredit/core/viz/binning_plots.py` 增加一个私有绘图辅助函数，职责限定为：

1. 校验 `solution_` 是与热力图一致的二维矩阵。
2. 将矩阵行方向转换为 `_cross_heatmap_cell` 的显示方向。
3. 按最终箱编号提取外轮廓线段。
4. 从项目现有连续色阶均匀采样边框颜色。
5. 将边界线叠加到指定 `Axes`，不改变坐标范围、刻度或其他图元。

`bin_2d_plot` 在五个 `_cross_heatmap_cell` 调用完成后，对五个目标 `Axes` 调用该辅助函数。颜色映射只计算一次并在五个子图间复用，保证同箱同色。

## 数据流

```text
OptimalBinning2D.solution_
        |
        v
校正为热力图显示方向
        |
        v
按最终箱提取外轮廓线段 + 按箱编号采样色阶
        |
        v
叠加到五个指标热力图
```

指标矩阵的计算和热力图着色保持原样；轮廓层只依赖最终箱映射，不依赖某个指标的数值。

## 边界与异常处理

- `solution_` 为空或不是二维矩阵时，抛出中文 `ValueError`，避免静默生成错误图形。
- `solution_` 形状与热力图形状不一致时，抛出中文 `ValueError`。
- 单一最终箱仍绘制整个热力图区域的外轮廓。
- 非矩形、凹形和 L 形箱按格网真实外缘绘制。
- 相邻最终箱的共享边界可能分别属于两个箱的轮廓；绘图顺序固定，确保五个子图结果一致且不产生位置偏移。

## 测试与验证

新增自动化测试覆盖：

- 手工构造含矩形、L 形及单格箱的 `solution_`，验证同箱内部边不生成、外轮廓完整。
- 验证五个目标指标子图均包含轮廓层，另外四个子图不增加该图层。
- 验证同一最终箱在五个子图中的颜色映射一致。
- 验证含缺失行和缺失列的二维分箱仍能正确绘制轮廓。
- 运行现有二维分箱和可视化测试，确认布局、标签及指标显示不回归。
- 使用 `examples/hscredit_yyp.xlsx` 生成实际 `bin_2d_plot` 图并进行视觉检查，确认边框贴合合并箱且未增加其他元素。
