# `bin_2d_plot` 二维分箱内缩彩色轮廓修复设计

## 背景与根因

`bin_2d_plot` 原实现把每个最终二维箱的轮廓画在预分箱网格边界上。相邻箱会重复绘制同一条共享边，后画颜色覆盖先画颜色；位于热力图边缘的轮廓还会覆盖坐标轴外框。连续渐变色中的相邻颜色差异也不足，导致最终箱归属不清晰。

二维分箱器的 `solution_` 映射和每个预分箱单元格的指标均正确，本次只修复联合图的轮廓层。

## 目标

- 每个最终二维箱使用一种高区分度类别色。
- 每个箱的完整轮廓向自身区域内轻微收缩。
- 共享边界两侧分别显示相邻箱自己的颜色，互不覆盖。
- 彩色轮廓不覆盖坐标轴外框。
- 同箱内部不绘制彩色边，保留原有细白色预分箱网格。
- 保留每个预分箱单元格原有的指标值和热力颜色，不回填最终箱统一指标。
- 每个最终箱在显示区域最高一行的最左单元格左上角显示一次实际箱 index，采用白底黑字。
- 除箱 index 外，不新增图例、点状标记或其他视觉元素。
- 五个交叉指标热力图复用相同的箱色、线段和线宽。
- 缺失值行和缺失值列按照 `solution_` 参与轮廓绘制。

## 方案

`_draw_2d_bin_boundaries` 按最终箱逐格检查四个方向，只为矩阵外侧或异箱相邻侧生成轮廓边。每条边沿法向和切向都向当前格内部移动 `0.04` 个单元格：

- 左边向右移动，右边向左移动。
- 下边向上移动，上边向下移动。
- 轮廓端点也沿边方向内缩，保证最外层线段严格位于坐标轴框内。

直线跨格接缝和凹角会因为端点内缩产生空隙，因此按原始网格顶点收集同一箱的轮廓端点并补短连接段。矩形、L 形和凹形箱都能形成连续的内缩轮廓；对角接触的独立区域按来源单元格分别闭合，避免错误连接。

箱色通过项目现有 `get_series_colors` 类别色板按箱编号顺序分配，并在五个指标子图间复用同一映射。

箱 index 直接使用 `solution_` 中的最终箱 ID。为兼容矩形、L 形和其他非矩形区域，每个箱取显示方向中最高一行，再取该行最左侧单元格作为唯一锚点；文本从该单元格左上角向内偏移，使用不透明白底和黑字，避免受不同热力颜色影响。

## 代码范围

- 修改 `hscredit/core/viz/binning_plots.py` 中的 `_draw_2d_bin_boundaries` 和 `bin_2d_plot` 轮廓调用。
- 修改 `tests/test_visualization/test_bin_plot_layout.py` 的轮廓与箱 index 单元测试、五面板一致性测试和缺失箱测试。
- 不修改 `OptimalBinning2D`、指标矩阵、KS 图、边缘分箱图或公开绘图参数。

## 测试与验证

- 手工 L 形映射验证共享边界两侧分别内缩、颜色不同且同箱内部无彩色边。
- 单一最终箱验证完整轮廓严格位于坐标轴框内。
- 验证五个指标热力图的轮廓 gid、颜色和线段完全一致，其他四个面板没有轮廓层。
- 验证五个指标热力图中每个最终箱各有一个位置一致的白底黑字 index，其他四个面板没有箱 index。
- 验证缺失行/列中的所有最终箱均生成轮廓和 index。
- 运行二维分箱和全部可视化回归测试。
- 使用 `examples/hscredit_yyp.xlsx` 生成 `中智小牛分C3 × CURRENT_DPD` 实图，检查类别色、共享边界、凹角连续性、白色网格、单元格数值和蓝色坐标轴外框。
