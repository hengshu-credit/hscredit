# `bin_2d_plot` 二维分箱单色边界修复设计

## 背景与根因

`bin_2d_plot` 当前按最终二维箱分别提取完整外轮廓，并为每个箱分配一种颜色。这个实现存在三个问题：

- 相邻最终箱会在同一位置各画一次共享边界，后绘制的颜色覆盖先绘制的颜色，边界归属和颜色不稳定。
- 位于热力图边缘的最终箱会在坐标轴边框上再次绘制彩色线，导致图表最外框被不同箱色分段覆盖。
- 连续色阶中的相邻颜色差异有限，且没有箱号或图例时，彩色外轮廓不能可靠表达分箱关系。

二维分箱器的 `solution_` 映射正确，本次只修复联合图的边界绘制，不修改分箱求解和指标计算。

## 目标

在 `bin_2d_plot` 的五个交叉指标热力图中，仅用一种深色边界标出不同最终二维箱之间的分界。

必须满足：

- 只有相邻单元格属于不同最终二维箱时才绘制分界线。
- 每条共享边界只绘制一次，所有分界线使用同一种深色。
- 不沿热力图最外圈绘制二维箱边界；最外框继续由坐标轴边框负责。
- 同一最终箱内部不绘制深色分界线，仍保留原有细白色预分箱网格。
- 保留每个预分箱单元格原有的指标数值和热力颜色，不回填统一的最终箱指标。
- 不新增箱号、标签、图例、标记或其他视觉元素。
- 五个交叉指标子图复用完全相同的边界线段、颜色和线宽。
- 缺失值行和缺失值列按照 `solution_` 中的归属参与相邻箱判断。

## 方案

将现有“逐箱绘制彩色完整外轮廓”改为“逐相邻单元格绘制单色共享边界”：

1. 将 `solution_` 行方向翻转，使其与 `_cross_heatmap_cell` 的显示方向一致。
2. 横向扫描每一对左右相邻单元格；箱编号不同时，在两格之间生成一条竖直线段。
3. 纵向扫描每一对上下相邻单元格；箱编号不同时，在两格之间生成一条水平线段。
4. 将全部线段放入一个 `LineCollection`，统一使用深色、固定线宽和高于热力图的层级。
5. 不检查矩阵外侧邻居，因此不会生成覆盖坐标轴外框的线段。

采用单一 `LineCollection` 可以从结构上消除共享边界重复绘制和颜色覆盖，而不需要偏移线条、双色虚线或额外标记。

## 代码结构

修改 `hscredit/core/viz/binning_plots.py`：

- 保留 `_draw_2d_bin_boundaries` 作为私有辅助函数，但将其输出改为单个单色 `LineCollection`。
- 将 `bin_colors` 参数替换为单个 `color` 参数，默认使用高对比深色。
- 删除 `bin_2d_plot` 中按最终箱编号采样连续色阶的逻辑。
- 五个热力图仍在相同位置调用边界辅助函数，不改变公开的 `bin_2d_plot` 参数和返回值。

不修改 `OptimalBinning2D`、交叉指标矩阵、边缘分箱图、KS 图或公共样式配置。

## 边界与异常处理

- `solution_` 为空或不是二维矩阵时，继续抛出中文 `ValueError`。
- `solution_` 形状与热力图不一致时，继续抛出中文 `ValueError`。
- 所有单元格属于同一最终箱时不产生内部边界，函数返回一个没有线段的边界集合。
- 非矩形、凹形和 L 形最终箱通过相邻关系生成准确的离散分界。
- 位于矩阵外侧的边不属于最终箱之间的共享边界，不生成额外线段。

## 测试与验证

自动化测试覆盖：

- 手工构造含 L 形合并箱的 `solution_`，验证同箱内部无深色边界、异箱共享边界只出现一次。
- 验证生成的线段不包含热力图最外圈，坐标轴四条边框的颜色和线宽不被边界层覆盖。
- 验证边界集合只使用一种颜色。
- 验证五个交叉指标子图具有相同的边界线段、颜色和线宽，其他四个子图没有边界层。
- 验证包含缺失行和缺失列时，边界矩阵形状和分界结果正确。
- 运行现有二维分箱与可视化测试，确认数值、热力颜色、布局和标签不回归。
- 使用 `examples/hscredit_yyp.xlsx` 生成真实 `bin_2d_plot` 图片进行视觉核验，确认最终箱分界清晰且外框完整。
