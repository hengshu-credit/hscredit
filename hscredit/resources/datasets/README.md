# hscredit 现金贷数据集

`hscredit` 是现金贷**单笔单批放款订单**数据集，每行对应一笔放款订单。风险特征取自该笔借据的授信给额环节，订单信息与贷后表现取自同一观察日期。

## 业务流程与时间口径

1. 客户从上游流量渠道进入，平台推送授信审批；`授信时间` 记录推送审批的时间。
2. 授信环节审批出客户的额度 `loan_amt` 与借款期限 `periods`。客户只能选择借或不借，不能自行调整额度与期数。
3. 客户取得额度和期限后，在前端主动提交借款申请；`放款时间` 记录这个提交时间，不能仅凭列名把它理解为资金实际到账时间。
4. 客户提交借款后，借款平台分发资金方，记录为 `放款银行`。它不是流量来源，也不能假定在授信审批输入时已经可得。
5. 在观察时点抽数，取得借据历史最大逾期、前 n 期历史最大逾期和当前逾期等贷后表现。

样本取自业务早期波动阶段。同期业务背景指标为**授信通过率 15%、支用借款率 70%**。文件仅收录形成放款订单的记录，计算这两项转化率还需对应的授信申请与获额客群总数。

## 数据集概况

| 项目 | 内容 |
| --- | --- |
| 数据集名称 | `hscredit` |
| 格式 | Parquet 文件 357.89 MiB，完整 DataFrame 约 7.16 GiB |
| 行数 / 字段数 | 111,929 / 8,516 |
| 唯一订单 / 唯一客户 | 111,929 / 110,283，同一客户可有多笔订单 |
| 资金方 / 流量渠道 | 6 / 8 |
| 授信时间范围 | 2023-12-15 09:01:02 至 2024-06-17 21:34:05 |
| 借款申请时间范围（`放款时间`） | 2023-12-15 00:00:00 至 2024-06-17 23:57:25 |
| 观察时点 / 抽数日期 | `etl_date = 2025-11-07` |
| 拆分后的字段数 | 订单信息 9，逾期数据 14，授信时点特征 X 8,493 |

文件大小按 Parquet 文件统计。内存占用按 pandas 2.3.3 的 `memory_usage(deep=True)` 计算，读取和拆分时还需额外的临时空间。

## 字段说明与拆分边界

### 订单信息

| 原始字段 | 含义 |
| --- | --- |
| `放款编码` | 放款订单编号，每笔订单唯一 |
| `用户编码` | 与客户身份证一一对应的脱敏身份标识；用于客户关联或分组，不是身份证原文 |
| `loan_amt` | 授信环节审批给客户的额度，样本取值为 3,000 至 14,000 |
| `periods` | 授信环节审批的借款期限，取值为 3、6、9、12 期 |
| `放款银行` | 客户提交借款后，由借款平台分发的资金方 |
| `流量渠道` | 客户来源：上游从哪个流量渠道获取的客户 |
| `授信时间` | 推送授信审批的时间，并非审批完成时间 |
| `放款时间` | 客户获得授信额度和期限后，主动提交借款申请的时间 |
| `etl_date` | 观察时点的抽数日期，取值为 2025-11-07，精度为天 |

编号、时间、额度、期限、资金方和渠道均归入订单信息。额度与期限是审批结果，使用时需结合模型的决策时点。样本中有 2,877 笔订单的借款申请时间记为授信当日零点，早于授信时间。按小时计算授信至借款间隔时，这部分订单需单独处理。

### 逾期数据

| 原始字段 | 含义 |
| --- | --- |
| `DPD` | 截至观察时点，该借据的历史最大逾期天数 |
| `MOB1` … `MOB12` | 出账订单前 n 期的历史最大逾期天数。例如 `MOB6` 取前六期的累计最大值 |
| `CURRENT_DPD` | 观察时点该借据的当前逾期天数 |

三类逾期字段均为本笔借据的贷后表现。已结清逾期的借据可能同时满足 `CURRENT_DPD = 0` 和 `DPD > 0`。解释 `MOBn` 时应结合合同期数、出账情况与观察日期核实表现期。短期限订单也可能在 `MOB12` 列有值。

### X：授信时点风险数据

| 字段或内容 | 含义 |
| --- | --- |
| `sex` | 性别编码；未提供编码到性别名称的字典，保持原值，不推断 0/1 对应关系 |
| `age_year` | 授信时点的年龄 |
| `province` | 身份证前两位对应的户籍省份编码，不是当前居住地 |
| 其余风险字段 | 该笔借据授信时点的多头、负债、还款、历史逾期、基础信息、社保、公共信息等风险数据 |

X 包含 8,493 个授信时点特征。数据按整列判断缺失码：若数值列的唯一负数是 `-1`，则该列的 `-1` 已存为缺失值，pandas 读取为 `NaN`。共处理 587 列，其中 74 列在替换后全为空值，仍保留在 X 中。另有 38 列同时含有 `-1` 和其他负数，其中的 `-1` 保留原值。

数值 0 和布尔值 False 均按原值保留。例如 `DJK_X986`、`DK_BALANCE`、`LZ_SCORE` 等均保留原名。现有资料未提供每个风险字段的完整数据字典，因此不根据缩写臆造计算公式、统计窗口、单位、评分方向或缺失码含义。X 中的授信前历史逾期信息与本笔借据的贷后 `DPD` / `MOBn` 是不同口径。

## 加载方式

通过 PyPI 安装后，首次调用 `hscredit_dataset()` 会从 [GitHub Release 下载完整 Parquet](https://github.com/hengshu-credit/hscredit/releases/download/v0.1.3/hscredit.parquet)。文件大小为 357.89 MiB，SHA-256 为 `6c4e4790f3a56472d36e58517df349aeb18d3ca709d6b424f51a6556fa8d14f9`。校验通过后可离线复用。默认缓存于 `~/.cache/hscredit/datasets/<SHA-256>/hscredit.parquet`，可用环境变量 `HSCREDIT_DATA_HOME` 指定缓存根目录。

通过 Git LFS 检出完整仓库时，函数优先读取 `hscredit/resources/datasets/hscredit.parquet`。两种安装方式均支持按列加载及拆分订单、逾期和特征数据。

从 Git 仓库安装时，先在仓库根目录运行 `git lfs pull` 获取 Parquet 数据文件，再安装或构建包。

从仓库或安装后的包均可调用同一接口，路径不依赖当前工作目录。Parquet 引擎 `pyarrow` 已列入基础依赖。

```python
from hscredit import hscredit_dataset
# 也可从 hscredit.utils 或 hscredit.utils.datasets 导入

# 默认读取 111,929 行、8,516 列
data = hscredit_dataset()
```

需要全量拆分时，使用 `order, overdue, X = hscredit_dataset(split=True)`。三个结果均为 `pandas.DataFrame`，保持相同的行索引和顺序。字段互不重叠、合计覆盖全部数据；各组内部保持原始字段顺序。函数不排序、不抽样、不填补缺失、不转换编码、不生成目标变量。

数据较宽，演示或分析少量字段时可以在读取阶段投影，避免一次载入全部特征：

```python
order, overdue, X = hscredit_dataset(
    split=True,
    columns=["用户编码", "授信时间", "loan_amt", "MOB1", "age_year", "sex", "province"],
)
# 此时三个结果仅包含 columns 中所选的对应字段；未选中的组为空列 DataFrame。
```

`columns` 不传表示全部字段；传入字段名序列时，读取顺序与所传序列一致。不存在或重复的字段名会报错。`columns=[]` 返回保留全部行索引的零列数据。

## 标签与建模使用

下面按订单统计 `MOB1` 和 `MOB6` 超过给定天数的比例。四种口径均使用该字段有值且非负的全部放款订单（111,929 笔），包含短期限订单。建模时可按所需表现期另外筛选样本。

| 标签定义 | 满足条件的订单数 | 占有效订单比例 |
| --- | ---: | ---: |
| `MOB1 > 0` | 11,696 | 10.45% |
| `MOB1 > 30` | 1,515 | 1.35% |
| `MOB6 > 0` | 34,660 | 30.97% |
| `MOB6 > 30` | 10,137 | 9.06% |

例如，可用 `MOB6 > 30` 构造坏样本标签。

```python
import pandas as pd
from hscredit import hscredit_dataset

order, overdue, X = hscredit_dataset(
    split=True,
    columns=["用户编码", "授信时间", "MOB6", "age_year", "LZ_SCORE"],
)
days = overdue["MOB6"]
valid = days.notna() & days.ge(0)
y = pd.Series(pd.NA, index=days.index, dtype="Int64", name="MOB6大于30天")
y.loc[valid] = days.loc[valid].gt(30).astype(int)
# 建模前还需按业务账单定义核实表现期成熟度；未确认的样本不直接视为好样本。
```

按客户划分样本时使用 `用户编码`，避免同一客户的不同订单跨训练集和测试集；评估未来批次时结合 `授信时间` 做时间外验证。本文件只有一个观察时点，不能将 `MOB1` 与 `CURRENT_DPD` 当作两个时点的当前状态，用来还原真实迁徙矩阵。
